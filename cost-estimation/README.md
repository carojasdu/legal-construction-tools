# Estimación de Costos de Equipos para Proyecto de
Construcción

Este directorio contiene los archivos relacionados con la primera prueba técnica propuesta. Los datos originales suministrados se encuentran en la carpeta `data/raw` para la fácil replicabilidad de los resultados. En la carpeta `notebooks` se encuentran los códigos preparados, uno con el EDA realizado sobre dichos datos, y otro con algoritmos de forecasting para la predicción de costo requerida. El informe requerido se encuentra en la `report/informe.md`, en formato Markdown. 

Al correr el notebook `01_EDA.ipynb`, se crean archivos adicionales en la carpeta `data/processed` que son usados en el notebook `02_forecasting.ipynb`, por lo que es requerido correrlos en orden, en caso de querer replicar los resultados.
